# Изменения

## 0.8.0-alpha.1 — 2026-08-15

Этап 8: конвертация форматов, пакетная обработка и командная строка.

- **Конвертация** (меню «⋯»): экспорт страниц в PNG/JPEG (96/150/300 DPI,
  все или текущая), извлечение всего текста в .txt, создание PDF из
  изображений (каждое — страница, размер по DPI из метаданных),
  объединение PDF-файлов (результат сразу открывается).
- **Пакетная обработка**: одна операция для набора файлов — оптимизация
  без потерь, защита паролем AES-256 или экспорт страниц в PNG; статус по
  каждому файлу, ошибки одного не прерывают остальные, отмена — после
  текущего файла.
- **NexusPdfCli.exe** в поставке: export-images, extract-text, merge,
  from-images, optimize, protect, ocr — те же движки, что и в приложении,
  локально и без интернета. Существующий результат не перезаписывается
  без --force; коды возврата 0/1/2; справка --help на русском.
- Все операции создают копии и проверяют результат повторным открытием;
  файл результата не может совпасть с исходным или открытым в программе.
- Тесты: 81 (32 unit + 49 интеграционных): экспорт в точных размерах DPI
  с поворотами, порядок текста, объединение с сохранением текста и
  честным отказом (цель = исходник, запароленный вход с именем файла),
  сборка PDF из изображений с попиксельной проверкой заливки.

## 0.7.0-alpha.1 — 2026-08-15

Этап 7: распознавание текста (OCR).

- **«Распознать текст (OCR)…»** (меню «⋯»): страницы-сканы распознаются
  локально движком Tesseract (русский + английский, без интернета). Поверх
  изображения добавляется НЕВИДИМЫЙ текстовый слой — после сохранения
  работают поиск и копирование, внешний вид страниц не меняется ни на
  пиксель (проверено попиксельным тестом).
- Объём на выбор: все страницы без текста или только текущая. Прогресс
  постранично с числом распознанных слов и отменой; уже распознанные
  страницы при отмене сохраняются, Ctrl+Z убирает слой постранично.
- Честные пропуски: страницы, где текст уже есть (настоящий или ранее
  распознанный), не распознаются повторно.
- Слова с низкой уверенностью отфильтровываются; итог показывает среднюю
  уверенность распознавания.
- Языковые модели (~8 МБ, tessdata_fast) поставляются с приложением и
  пинуются по SHA-256 (tools/tessdata.lock.json); без них пункт меню
  честно скрыт.
- Тесты: 73 (32 unit + 41 интеграционный): скан → распознан (кириллица и
  латиница) → сохранён → текст ищется, растр не изменился; страницы с
  текстом пропускаются; повторный запуск не наслаивает второй слой.
- Ревизия этапа (12 фиксов): невидимые слова растягиваются в рамку скана
  по ОБЕИМ осям (раньше слой из заглавных был мельче чернил и выделение
  съезжало по вертикали); OCR-растр рендерится без аннотаций и полей форм
  (их текст не запекается в страницу); страница с ЛЮБЫМ настоящим текстом
  пропускается (раньше порог 8 символов давал невидимый дубль коротких
  надписей); отмена и ошибки середины прогона показывают частичный итог,
  повторное закрытие окна прогресса не ждёт зависший нативный вызов;
  пустые сканы считаются отдельно, а не как «текст уже есть»; средняя
  уверенность считается по показанным словам; при сбое инициализации
  Tesseract пункт меню объясняет причину и скрывается; OCR-тесты без
  языковых моделей падают громко, CI скачивает qpdf и tessdata перед
  тестами. Тестов стало 75.

## 0.6.0-alpha.1 — 2026-08-15

Этап 6: криптографические цифровые подписи.

- **Проверка подписей**: при открытии подписанного PDF в статус-баре появляется
  значок «Подписи действительны» / «Проблема с подписью»; клик открывает
  подробности по каждой подписи — подписант, время, причина/место,
  криптографическая целостность, изменялся ли документ после подписания,
  доверие цепочки сертификата. Собственный инспектор: PKCS#7/SignedCms,
  X509Chain, анализ ByteRange.
- **Подписание сертификатом** («⋯» → «Подписать сертификатом…»): сертификаты
  из личного хранилища Windows или файла PFX/P12, причина и местоположение,
  невидимая подпись PKCS#7 (SHA-256) через инкрементальное обновление файла —
  байты документа не переписываются, как требует стандарт. Созданная подпись
  сразу проверяется собственным инспектором.
- Честные ограничения (задокументированы): видимое поле подписи, метка
  времени TSA, несколько подписей и подписание запароленных файлов — в
  следующих итерациях; совместимость проверена собственным инспектором и
  PDFium (ручная проверка в Adobe Acrobat не проводилась).
- Тесты: 65 (32 unit + 33 интеграционных): подписание self-signed
  сертификатом → валидность/недоверенность/полное покрытие; порча байта →
  подпись недействительна; дописывание после подписи → «документ изменён»;
  подписание документа с AcroForm сохраняет форму.
- Security-ревизия этапа (9 фиксов): инспектор отвергает файлы, где дыра
  ByteRange шире значения /Contents (атака «валидно + покрывает весь файл»
  с неподписанными байтами); зелёный статус подписи теперь требует ДОВЕРИЯ
  к цепочке сертификата — криптографически верная, но недоверенная подпись
  показывается жёлтым «Подпись верна, сертификат не доверен»; метаданные
  подписи (/M /Name /Reason /Location) читаются строго из словаря подписи,
  а не из соседних объектов файла; подписыватель корректно дополняет
  косвенные массивы /Annots и /Fields (раньше ссылка попадала в /MediaBox),
  не путает «N 0 obj» внутри данных потоков с настоящими объектами и не
  обрезает словари на «>>» внутри строк (JavaScript в /OpenAction); отказ
  «документ уже подписан» перепроверяется в самом сервисе по исходному
  файлу — гонка с фоновой инспекцией больше не может уничтожить чужую
  подпись. Тестов стало 70.

## 0.5.0-alpha.1 — 2026-08-14

Этап 5 (часть 2): заполнение PDF-форм (AcroForm).

- **Кнопка «Формы»** появляется автоматически у документов с AcroForm:
  кликните поле — и вводите текст (Backspace, Delete, стрелки, Home/End
  работают); флажки переключаются кликом. Поля подсвечены голубым.
- **Прямое сохранение**: документ без структурных правок сохраняется как
  есть — с заполненными значениями форм, закладками, вложениями и всей
  структурой (раньше любое сохранение шло через перекомпоновку страниц,
  которая переносит только страницы и аннотации).
- Честное предупреждение: если у документа с формой были структурные правки
  (порядок/повороты/новый контент), при сохранении форма преобразуется в
  статичный вид — статусная строка сообщает об этом явно.
- XFA-формы не поддерживаются (кнопка не показывается) — задокументировано.
- Тесты: 60 (32 unit + 28 интеграционных), включая полный цикл «клик в поле →
  ввод → сохранение → значение читается из файла» и редактирование Backspace.
- Серверы сборки .NET SDK гасятся после релизной сборки (`-All`) — больше
  никаких висящих «.NET Host» после работы среды разработки.

### Исправления по итогам адверсариальной ревизии этапа 5b (9 подтверждённых)

- Ввод в форму теперь помечает документ изменённым: закрытие вкладки
  предупреждает о несохранённых значениях (раньше — тихая потеря).
- Значение редактируемого поля фиксируется перед ЛЮБЫМ сохранением
  (копия/извлечение/оптимизация/защита), а не только перед прямым.
- Прямое сохранение запароленного документа работает: пароль открытия
  пробрасывается в валидацию и переоткрытие; защита копии сохраняется
  (+ регрессионный тест).
- Выход из режима «Формы» полностью закрывает форм-окружение: голубая
  подсветка полей исчезает с экрана и не попадает в печать.
- Undo/водяной знак во время заполнения больше не «замораживают» страницу:
  ссылка на активную страницу формы переназначается после перестройки.
- До первого клика в поле клавиши остаются у прокрутки (Home/End/стрелки
  не глотались впустую).
- Набор текста не хоронит мегабайты устаревших растров в LRU-кэше;
  миниатюра страницы обновляется вместе с введёнными значениями.

## 0.4.0-alpha.1 — 2026-08-14

Этап 5 (часть 1): комментарии и аннотации + фикс процессов-зомби.

- **Критический фикс**: каждое закрытие приложения оставляло процесс-зомби
  без окон (deadlock sync-over-async при выходе). Проверено автотестом
  «окно закрыто → процесс завершился». Спасибо за наводку!
- **Заметки-комментарии**: текст + автор, размещение кликом, жёлтый значок.
- **Маркер-выделение, рамка, овал**: растягивание рамкой прямо по странице
  (живая пунктирная рамка при перетаскивании).
- **Панель комментариев**: все аннотации документа (существующие в файле —
  только чтение, свои черновики — с удалением), переход к странице по клику,
  бейдж «черновик» до сохранения.
- Аннотации создаются как настоящие PDF-аннотации (Text/Square/Circle) при
  сохранении: видны в других просмотрщиках, текст и автор читаются обратно;
  учитывается поворот страницы после размещения.
- Тесты: 56 (32 unit + 24 интеграционных).

### Исправления по итогам адверсариальной ревизии этапа 5a (8 подтверждённых)

- Значок заметки при повороте страницы после размещения переносится по
  центру (мог уехать за край страницы и «пропасть»).
- Потеря mouse capture (Alt+Tab) или Esc посреди растягивания рамки больше
  не оставляет залипшую рамку и не создаёт ложную аннотацию.
- Удаление черновика из панели идёт по ссылке на объект — устаревшая строка
  панели больше не может удалить чужой черновик.
- Вторичный экземпляр больше не стирает crash-метку работающего первичного
  (ломало восстановление после краха).
- Предпросмотр черновиков пересчитывается при повороте страницы тем же
  кодом, что и запекание (общий OverlayDisplayMapper + 5 unit-тестов).
- Панель комментариев: перекрывающиеся обновления не публикуют устаревший
  снимок (version-guard).
- Передача файла в свёрнутое окно разворачивает его.
- Горячий цикл pipe-сервера при персистентной ошибке заменён backoff
  100 мс → 5 с.

## 0.3.0-alpha.1 — 2026-08-14

Этап 4: наложение нового контента с запеканием в PDF.

- **Колонтитулы и номера страниц**: шаблоны {n}/{N}/{file}/{date}, верх/низ,
  выравнивание, диапазон страниц, пропуск первой; одна операция Undo.
- **Водяной знак**: текст, размер, непрозрачность, диагональ 45°, диапазон.
- **Добавление текста**: диалог (текст, размер, цвет) + размещение кликом по
  странице (курсор-прицел, Esc — отмена); кириллица встраивается подмножеством
  системного TTF (Segoe UI, CID) — текст ищется и копируется в результате.
- **Вставка изображения** (PNG/JPEG/BMP/TIFF): ширина в % страницы,
  размещение кликом, прозрачность PNG сохраняется.
- **Визуальная подпись**: локальная библиотека шаблонов, зашифрованная DPAPI
  (ключ учётной записи Windows), превью, вставка в документ. Честно помечена
  как изображение, не криптографическая подпись.
- Живой предпросмотр всего наложенного в режиме чтения до сохранения;
  контент запекается в содержимое страниц при сохранении (учтён /Rotate и
  добавочный поворот). Всё обратимо через Ctrl+Z до сохранения.
- Тесты: 50 (27 unit + 23 интеграционных), включая кириллический оверлей,
  повёрнутую страницу и пиксельную проверку изображения.

### Исправления по итогам адверсариальной ревизии этапа 4 (9 подтверждённых)

- Запекание считало координаты от MediaBox, а экран живёт в CropBox —
  на «типографских» PDF подпись уезжала бы на сантиметры; теперь рамка
  CropBox∩MediaBox, как у рендера.
- Поворот страницы ПОСЛЕ размещения оверлея больше не теряет контент:
  ориентация фиксируется в момент размещения (PlacedRotation), при
  сохранении координаты и угол пересчитываются в итоговую рамку
  (+ пиксельный регрессионный тест).
- Клик размещения во время сохранения игнорируется (правка молча не
  исчезает), курсор-прицел снимается при старте сохранения.
- Лимит 24 Мп на вставляемые изображения с даунскейлом — стомегапиксельные
  фото больше не раздувают память до OutOfMemory; устранено int-переполнение.
- Библиотека подписей показывает эскизы (128 px) вместо полных растров,
  полный декод — только при вставке.
- Предпросмотр текста выровнен с запечённым результатом по базовой линии
  (WPF 1.079·em против 0.75·em) и вращается вокруг той же точки.
- «NaN» в размере шрифта отклоняется валидацией (и защитой в движке).
- Устранена утечка нативного image-объекта при ошибке запекания.
- Одиночный экземпляр: залповое открытие файлов из Проводника больше не
  плодит копии приложения (параллельные pipe-серверы, таймаут 4 с) —
  найдено на живой сессии пользователя с шестью процессами.

## 0.2.0-alpha.1 — 2026-08-14

Установщик с интерфейсом, печать, защита паролем, оптимизация.

- **Фирменный установщик NexusPdfSetup.exe** (WPF): hero-панель, выбор
  «для меня / для всех», путь установки, ярлык на рабочий стол, лицензия,
  прогресс, запуск после установки; тихий режим `/S [/allusers] [/dir=…]
  [/nodesktop]`. Под капотом — корректный MSI (обновления/восстановление/
  удаление через «Установленные приложения»).
- MSI переделан: **x64** (был x86 по умолчанию WiX), запасной мастер WixUI
  на русском с лицензией, иконка продукта, опция ярлыка на рабочем столе.
  Полный цикл «установка → проверка → запуск → удаление» прогнан автоматически
  на Windows 11: следов после удаления нет.
- **Печать** (Ctrl+P): все/текущая/диапазон, вписать/фактический размер,
  системный выбор принтера и копий; рендер и отправка — на фоновом потоке.
- **Защита паролем**: копия документа с шифрованием AES-256 (qpdf),
  с проверкой открытия результата.
- **Оптимизация без потерь**: объектные потоки + пересжатие (qpdf),
  отчёт «размер до → после»; результат проверяется PDFium и qpdf --check.
- qpdf 12.4.0 поставляется с приложением (версия и SHA-256 запинены).
- Поле перехода к странице в статус-баре, иконка приложения и окон,
  тень страниц, portable ZIP, контрольные суммы артефактов.
- Исправлено: два экземпляра PDFium-движка в одном процессе роняли его
  (глобальная инициализация PDFium) — теперь общий поток на процесс.

### Исправления по итогам адверсариальной ревизии (11 подтверждённых дефектов)

- **«Сохранить» в собственный файл не работал вовсе**: Windows не позволяет
  заменить файл с активным отображением в память; дескрипторы цели теперь
  освобождаются после проверки результата и перед подменой (+ регрессионный тест).
- **Каждое успешное сохранение ломало интерфейс**: событие изменения сессии
  приходило с фонового потока и рушило привязанные коллекции — теперь
  маршалится на поток диспетчера; освобождение старых дескрипторов при
  переоткрытии защищено finally (утечка блокировки файла исключена).
- **Восстановление сессии было мёртвым**: список открытых файлов писался
  только после закрытия всех окон (всегда пустой) — теперь поддерживается
  актуальным при каждом открытии/закрытии, так что работает и после краха.
- Печать против закрытия вкладки/сохранения: документ под операцией нельзя
  закрыть или пересохранить; в PDFium-дескрипторе устранена гонка
  dispose/рендер (нативный use-after-free).
- Пароли qpdf убраны из командной строки процесса (response-файл @args
  с немедленным удалением).
- qpdf с кодом 3 (успех с предупреждениями) больше не трактуется как отказ —
  оптимизация/шифрование работают на реальных «слегка кривых» PDF.
- Поиск: поздняя континуация отменённого поиска не воскрешает устаревшие
  совпадения; снапшот списка страниц исключает гонку с правками из UI.
- Установщик: тихий /allusers без прав возвращает честный код 740 вместо
  зависшего UAC; смена режима per-user↔per-machine блокируется с объяснением
  (Windows Installer не обновляет через границу контекстов); путь установки
  валидируется; запись копий поверх файла, открытого в другой вкладке,
  запрещена с понятным сообщением.
