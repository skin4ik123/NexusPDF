# Изменения

## 0.2.0-alpha.1 — 2026-08-14

Установщик с интерфейсом, печать, защита паролем, оптимизация.

- **Фирменный установщик NexusPdfSetup.exe** (WPF): hero-панель, выбор
  «для меня / для всех», путь установки, ярлык на рабочий стол, лицензия,
  прогресс, запуск после установки; тихий режим `/S [/allusers] [/dir=…]
  [/nodesktop]`. Под капотом — корректный MSI (обновления/восстановление/
  удаление через «Установленные приложения»).
- MSI переделан: **x64** (был x86 по умолчанию WiX), запасной мастер WixUI
  на русском с лицензией, иконка продукта, опция ярлыка на рабочем столе.
  Полный цикл «установка → проверка → запуск → удаление» прогнан автоматически
  на Windows 11: следов после удаления нет.
- **Печать** (Ctrl+P): все/текущая/диапазон, вписать/фактический размер,
  системный выбор принтера и копий; рендер и отправка — на фоновом потоке.
- **Защита паролем**: копия документа с шифрованием AES-256 (qpdf),
  с проверкой открытия результата.
- **Оптимизация без потерь**: объектные потоки + пересжатие (qpdf),
  отчёт «размер до → после»; результат проверяется PDFium и qpdf --check.
- qpdf 12.4.0 поставляется с приложением (версия и SHA-256 запинены).
- Поле перехода к странице в статус-баре, иконка приложения и окон,
  тень страниц, portable ZIP, контрольные суммы артефактов.
- Исправлено: два экземпляра PDFium-движка в одном процессе роняли его
  (глобальная инициализация PDFium) — теперь общий поток на процесс.

## 0.1.0-alpha.1 — 2026-08-14

Первый работающий срез (этапы 0–2 плана).

- Просмотрщик: вкладки, несколько окон, отделение вкладки, ленивый рендер с
  виртуализацией и LRU-кэшем, масштаб (Ctrl+колесо, по ширине, страница,
  100%), миниатюры, статус-бар, юникод-пути, защищённые паролем файлы.
- Поиск по текстовому слою с подсветкой и переходами.
- Систематизация страниц: мультивыбор, поворот 90/180/270 (метаданные, без
  растеризации), дублирование, удаление, перестановка перетаскиванием,
  извлечение выбранных страниц в новый PDF, Undo/Redo.
- Безопасное сохранение: временный файл на том же томе → проверка повторным
  открытием → атомарная замена; оригинал не изменяется при ошибке.
- RU/EN локализация, светлая/тёмная/системная тема, Per-Monitor V2 DPI,
  одиночный экземпляр, восстановление сессии после сбоя.
- Тесты: 24 unit + 11 интеграционных PDFium (все зелёные).
- Документация: архитектура, лицензии, безопасность, ограничения, матрица
  тестов, руководство.

Известные ограничения — docs/KNOWN_LIMITATIONS.md.
