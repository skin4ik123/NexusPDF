# Матрица тестирования

## Автоматические тесты

`tests/NexusPdf.UnitTests` — 24 теста (домен и инфраструктура):

- парсер диапазонов страниц: порядок перечисления, убывающие диапазоны,
  отказ по мусору/выходу за границы, текст ошибки;
- операции: поворот (нормализация четвертей), удаление вразброс + точный
  откат, запрет удаления всех страниц, перемещение блока вперёд/назад +
  откат, дублирование, вставка чужих страниц;
- Undo/Redo: цепочки, признак изменённости через счётчик версий
  (undo к точке сохранения снимает признак);
- настройки: json-roundtrip, повреждённый файл → значения по умолчанию,
  недавние файлы (дедупликация, лимит);
- атомарная запись: успех заменяет цель, провал валидации оставляет оригинал
  нетронутым и не оставляет temp-мусора, резервная копия по флагу.

`tests/NexusPdf.PdfEngineTests` — 11 интеграционных тестов реального PDFium
(они же — «engine spike» из ТЗ, фиксация фактических возможностей):

- открытие: количество и размеры страниц; размер учитывает `/Rotate`;
  кириллический путь; типизированная ошибка на не-PDF;
- рендер: непустые пиксели заданного размера;
- текстовый слой: извлечение, прямоугольники фрагмента;
- компоновка: перестановка + подмножество + поворот → сохранение → повторное
  открытие с проверкой размеров и текста страниц;
- SaveService: операции сессии применяются, оригинал байт-в-байт неизменен
  при «Сохранить как», признак изменённости снимается;
- сохранение «в себя» (цель = открытый отображённый в память файл) — работает,
  документ переоткрывается; копии поверх открытого источника отклоняются
  с типизированной ошибкой;
- извлечение выбранных страниц; поиск по нескольким страницам.

`QpdfEngineTests` — 5 интеграционных тестов qpdf (пропускаются, если бинарник
не установлен):

- `--check` на корректном файле и на мусоре;
- шифрование AES-256 → PDFium требует пароль → открывается с паролем,
  текст читается;
- снятие защиты возвращает открываемость;
- оптимизация сохраняет число страниц и текст, результат проходит `--check`.

Фикстуры генерируются кодом (`PdfFixture`) — в репозитории нет чужих PDF.

## Автоматизированные проверки на машине (Windows 11, 2026-08-14)

- смоук приложения: запуск exe с путём к PDF → документ загружен (по журналу),
  предупреждений рендера нет, процесс стабилен;
- **полный цикл установщика (per-user)**: `NexusPdfSetup.exe /S` → код 0;
  проверены файлы (exe, qpdf, уведомления), ProgID, OpenWithProgids, ярлык
  меню «Пуск», запись 0.2.0 в «Установленные приложения»; запуск
  установленного приложения с документом; `msiexec /x /qn` → код 0, следов
  (файлы/реестр/ярлыки/запись пакета) не осталось.

## Ещё не покрыто (план)

- печать (нет автоматического пути без диалога драйвера);
- per-machine установка (нужен UAC);

- перф-замеры на 100/1000 страниц и файлах >500 МБ.
