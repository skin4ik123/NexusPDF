  1. Названия шрифтов показаны их же начертанием.
  2. «In this document» — шрифты, которыми уже написан документ. Если такого шрифта нет в Windows (Helvetica), подставляется ближайший похожий — видно, каким он напишется.
  3. Шрифт без кириллицы выбрать можно для латиницы; при вводе русских букв программа предупредит сразу, а не после сохранения.
  4. Шрифт, который автор запретил встраивать, в PDF не попадёт — он выключен с объяснением.

3. Как с блоком работать

Щелчок с инструментом TextБлок без переноса: растёт вправо, пока пишешь (как надпись в Acrobat).
Протянуть рамкуБлок заданной ширины, текст переносится по словам, высота растёт сама (или фиксированная — галочка Auto height).
Enter / Shift+EnterНовый абзац / новая строка внутри абзаца.
Щелчок мимо или EscЗакончить ввод: щелчок — сохранить набранное, Esc — тоже сохранить и выйти, Ctrl+Z — отменить.
Один щелчок по готовому блокуВыделить: перетащить, растянуть, повернуть, Delete — удалить, Ctrl+D — копия.
Двойной щелчокСнова писать в блоке — в том числе после сохранения файла и повторного открытия.
Стрелки при выделенном блокеСдвиг на 1 пт, с Shift — на 10 пт.
