# Как интерфейс подстраивается

## Профили рабочих пространств

Одна и та же программа используется по-разному, и панели для этого нужны
разные. Профиль — набор состояний интерфейса под задачу; переключается в меню
программы, запоминается между запусками.

| Профиль | Рельс | Панель комментариев | Боковая панель | Масштаб |
|---|---|---|---|---|
| Чтение | нет | скрыта | оглавление (если есть) | страница целиком |
| Правка | «Правка» | скрыта | миниатюры | по ширине |
| Рецензирование | «Комментарии» | открыта | миниатюры | по ширине |
| Страницы | «Страницы» | скрыта | режим систематизации | — |

При открытии документа восстанавливаются только панели: масштаб оставляет за
собой начальная подгонка страницы. Перебивать её на каждом открытии — значит
спорить с пользователем.

## Плотность

Размеры кликабельных мест берутся из ресурсов (`UxTouchTarget`, `UxRowHeight`,
`UxGlyphSize`, `UxFontSize`, `UxToolPadding`) и меняются на лету — см.
`TOUCH_AND_PEN_SPEC.md`. Стили ссылаются на них через `DynamicResource`,
поэтому переключение не требует пересоздания окна.

## Что появляется и исчезает по состоянию

| Элемент | Когда виден |
|---|---|
| Панель свойств объекта | когда объект выбран |
| Контекстная полоса инструментов | когда выбрана группа на рельсе |
| Вкладка «Оглавление» | когда у документа есть закладки |
| Группа «Формы» на рельсе | когда в документе есть AcroForm |
| Значок подписей в строке состояния | когда документ подписан |
| Объём «Выбранные страницы» в центре печати | когда печать пришла из выбора |

Правило одно: пустая панель, которая ничего не сообщает, места не занимает.

## Строка состояния

Три колонки: слева номер и размер страницы, посередине сообщение о последнем
действии (обрезается многоточием), справа управление масштабом. Раньше это
были две наложенные панели, и при крупных размерах элементов длинный текст
прятал проценты масштаба вместе с кнопками.

## Окно при первом запуске

Стартовый размер 1200×800 вписывается в рабочую область: на ноутбучных экранах
1440×900 при системном масштабе 125–150 % окно уезжало за край, и часть
интерфейса была недоступна. Не помещается — окно разворачивается.

## Главное меню

Меню программы — разделы с подменю, а не список из двадцати пяти пунктов
подряд: «Файл», «Правка», «Страницы», «Содержимое», «Комментарии», «Защита»,
«Распознавание», «Преобразование», «Документ», затем «Вид», «Настройки» и
«О программе».

Собирается из реестра команд по `AppMenuTree`, поэтому пункт меню не может
разойтись с одноимённой кнопкой панели, а новая команда появляется в своём
разделе, а не отдельной строкой в конце списка. Доступность и причины
недоступности — те же, что везде.

## Скрытие панелей

«Вид → Панели» — отметки для каждой панели: панель инструментов, рельс групп
слева, миниатюры и оглавление, комментарии справа, свойства объекта, строка
состояния. Отметки применяются сразу и запоминаются между запусками.

«Только страница» (Ctrl+F11) прячет всё сразу; повторное нажатие возвращает
ИМЕННО ТУ раскладку, которая была до скрытия, а не набор по умолчанию.

Кнопка меню в правом верхнем углу остаётся видимой всегда, включая режим
«только страница»: спрятать последний способ управлять программой нельзя.

## Чего пока нет

- Перестановка панелей мышью и сохранение пользовательских профилей: профили
  встроенные, свой набор не создаётся.
- Отдельная раскладка для узкого окна (панели просто сжимаются).
- Полноэкранный режим чтения скрывает рамку окна, но не панели.
