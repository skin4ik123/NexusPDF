# Матрица поддержки интерактивного PDF

Дата: 2026-08-15, версия 0.16.0-alpha.1.

Правило этого документа: строка попадает сюда только после ИЗМЕРЕНИЯ.
В колонке «чем доказано» указан тест или проверка живого приложения. Там,
где написано «нет», функции нет и в интерфейсе она не показывается.

## Что такое интерактивный PDF

Всё, что в документе не является просто нарисованной страницей: ссылки,
поля форм, комментарии, закладки, слои, вложения, скрипты и подписи. Ниже —
что программа с этим делает.
