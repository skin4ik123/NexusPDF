# Матрица функций

Дата: 2026-08-15, версия 0.16.0. В интерфейсе **81 команда**; ниже они
сгруппированы по назначению. Статус присвоен по фактической проверке
(автотест, прогон на реальном документе или ручной прогон), а не по
наличию метода.

Легенда статусов: **Verified** — проверено; **Verified with limitations** —
работает с явно записанным ограничением; **Not implemented** — отсутствует
и в интерфейсе не показывается.

Общее правило продукта соблюдено: команд, которые видны, но не работают,
не найдено. Функции без движка (OCR без языковых моделей, qpdf-операции без
qpdf, правка в редакторе без редактора) скрываются из меню целиком.
