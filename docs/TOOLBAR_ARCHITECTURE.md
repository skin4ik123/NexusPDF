# Устройство панелей инструментов

## Быстрая панель

Верхняя панель больше не описана в разметке кнопка за кнопкой. Она строится из
списка идентификаторов команд, а каждая кнопка берёт название, значок,
подсказку, сочетание клавиш и доступность из реестра команд.

```
AppSettings.QuickCommands ──► QuickPanelLayout.Sanitize ──► QuickPanel.Items ──► ItemsControl
                                       │                          │
                              CommandRegistry              UxCommandHub.Invoke
```

Из этого следуют три свойства, которых не было у прежней панели:

1. **Состав меняет пользователь.** Меню программы → «Настроить быструю
   панель…»: слева всё, что умеет программа, справа — то, что вынесено;
   стрелки задают порядок, «—» добавляет разделитель.
2. **Кнопка не может разойтись с пунктом меню**: описание у них одно.
3. **Выключенная кнопка объясняет себя.** Подсказка показывает название,
   сочетание клавиш и причину недоступности — «Сначала откройте документ»,
   «Автор документа запретил печать».

Доступность пересчитывается по общему сигналу WPF `CommandManager.
RequerySuggested`, а не ручным «обнови панель» из двадцати мест.

### Чистка сохранённого состава

`QuickPanelLayout.Sanitize` (проект `NexusPdf.Ux`, покрыт тестами):

- команда, исчезнувшая из программы, молча выбрасывается — настройка могла
  остаться от прошлой версии;
- повтор одной команды убирается;
- два разделителя подряд схлопываются, крайние отбрасываются;
- если после чистки не осталось ни одной команды, берётся набор по умолчанию:
  пустая полоса без кнопок не бывает чьим-то осознанным выбором.

### Набор по умолчанию

Открыть · Сохранить · Сохранить как… · Печать | Отменить · Повторить | Поиск

## Контекстная полоса групп инструментов

Под быстрой панелью живёт полоса выбранной группы (комментарии, правка, формы,
защита). Она пока описана в разметке: у её элементов есть собственное
состояние (цвет и толщина линии, режим формы), которое не сводится к «команда
+ доступность». Это осознанное ограничение, а не недоделка — переносить её в
реестр имеет смысл вместе с панелью свойств выделенного объекта.

## Размеры

Все размеры панели идут от плотности интерфейса
(`UxTouchTarget`, `UxToolPadding`, `UxGlyphSize`) — см. `TOUCH_AND_PEN_SPEC.md`.
Кнопка панели не может быть меньше минимальной цели: это задано в стиле
`ToolButton` через `MinHeight`/`MinWidth`, а не подобрано отступами.

## Строка состояния

Три колонки: слева номер и размер страницы, в середине — сообщение о последнем
действии (обрезается многоточием), справа — управление масштабом. Раньше это
были две наложенные панели, и при крупных размерах элементов длинный текст
состояния прятал проценты масштаба и кнопки.
