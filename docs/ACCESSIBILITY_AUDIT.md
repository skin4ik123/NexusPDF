# Аудит доступности

Дата: 2026-08-15. Проверка выполнена на запущенной программе через дерево
UI Automation (тот же источник данных, который читает экранный диктор), а
не по коду разметки.

## 1. Что было до аудита

- `AutomationProperties` — **ни одного** во всём интерфейсе.
- Кнопки панели инструментов содержат только значок шрифта Segoe MDL2,
  поэтому диктор не мог назвать ни одну из них.
- Индикация фокуса с клавиатуры у кнопок панели была **невидимой**:
  триггер `IsKeyboardFocused` красил `BorderBrush` рамки, у которой
  толщина равна нулю; вдобавок `FocusVisualStyle` был отключён (`x:Null`).
- У кнопок диалогов (`PrimaryButton`, `LinkButton`) собственной индикации
  фокуса не было вовсе — только системный пунктир по умолчанию.

## 2. Что исправлено

| Проблема | Решение |
| --- | --- |
| Кнопки без имени | Имя берётся из той же подсказки, что видит зрячий пользователь — одним сеттером в стиле `ToolButton`, а не 32 правками разметки |
| Невидимый фокус на панели | Рамка кнопки всегда имеет толщину 2 и прозрачный цвет; при фокусе меняется только цвет — фокус виден и содержимое не «прыгает» |
| Нет фокуса в диалогах | У `PrimaryButton` добавлено внешнее кольцо фокуса, у `LinkButton` — рамка акцентного цвета |
| Неотличимое «выключено» | Явная прозрачность 0.45 для отключённых кнопок в обоих стилях |
| Безымянные области | Список страниц, список миниатюр и поле поиска получили имена |

## 3. Результат измерения (проверено)

Дерево UI Automation запущенной программы с открытым документом:

```
Окно: 'Bills.pdf — NexusPDF'
Кнопок в дереве: 21
С именем: 21   БЕЗ имени: 0
Списки: 'Миниатюры страниц' | 'Страницы документа' | …
```

Примеры имён, которые теперь произносит диктор: «Открыть PDF (Ctrl+O)»,
«Сохранить как… (Ctrl+Shift+S)», «Режим систематизации страниц»,
«Маркер-выделение (растяните рамку)», «Вымарать область (содержимое будет
УДАЛЕНО при сохранении)».

## 4. Управление с клавиатуры

Доступны без мыши (проверено по таблице `InputBindings` и работе команд):
открытие `Ctrl+O`, сохранение `Ctrl+S` и `Ctrl+Shift+S`, печать `Ctrl+P`,
поиск `Ctrl+F`, закрытие вкладки `Ctrl+W`, отмена/повтор `Ctrl+Z`/`Ctrl+Y`,
масштаб `Ctrl+=`/`Ctrl+-`/`Ctrl+1`/`Ctrl+0`, переключение вкладок
`Ctrl+Tab`, полный экран `F11`, **новое**: копирование выделенного текста
`Ctrl+C`, выделение текста страницы `Ctrl+A`, снятие выделения `Esc`.

## 5. Честные ограничения

- **Проверка живым диктором (Narrator) не проводилась** — измерено дерево
  автоматизации, а не произнесённая речь.
- В дереве остаются 6 безымянных элементов типа «список» — это
  декоративные слои внутри страницы (подсветка поиска, выделение,
  предпросмотр накладываемого содержимого). Они не мешают работе, но
  создают шум при навигации по элементам; убрать их из дерева —
  отдельная задача.
- Порядок обхода `Tab` не переопределялся: используется порядок разметки.
  Он логичен для панели инструментов и диалогов, но формально не проверен
  на всех экранах.
- Режим высокой контрастности Windows отдельно не тестировался.
- Настройка «уменьшить движение» не учитывается: анимаций в интерфейсе
  практически нет.
- Размер элементов рассчитан на мышь и перо; сенсорные цели (44×44 px)
  не выверялись.
