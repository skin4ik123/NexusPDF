# Краткое руководство

## Открытие

- Кнопка «Открыть», перетаскивание PDF в окно, двойной клик по файлу
  (после назначения программы обработчиком), или `NexusPdf.exe файл.pdf`.
- Защищённый файл спросит пароль; пароль нигде не сохраняется.

## Просмотр

- Прокрутка — колесо/полоса; масштаб — Ctrl+колесо, кнопки «−/+» в статус-баре,
  «по ширине», «страница целиком», Ctrl+1 — 100%.
- Слева — миниатюры, клик переходит к странице.
- Ctrl+F — поиск: Enter — дальше, Shift+Enter — назад, Esc — закрыть.
- Вкладки: Ctrl+Tab — следующая, Ctrl+W — закрыть. Меню «⋯» → «Открыть вкладку
  в отдельном окне» переносит документ в новое окно.
- F11 — полноэкранный режим (Esc — выход).

## Систематизация страниц (кнопка «Страницы»)

- Клик — выбор; Ctrl/Shift — несколько; Ctrl+A — все.
- Перетаскивание выбранных — изменение порядка (линия показывает место вставки).
- Кнопки панели: поворот ⟲/⟳/180°, дублирование, удаление (или Del),
  «Извлечь в новый PDF…» — сохраняет выбранные страницы отдельным файлом.
- Любая операция отменяется: Ctrl+Z / Ctrl+Y.

## Сохранение

- Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как.
- Исходный файл не изменяется, пока новый не записан и не проверен; при любой
  ошибке оригинал остаётся нетронутым.
- Точка «●» на вкладке — несохранённые изменения. При закрытии окна программа
  покажет список изменённых документов.

## Настройки

Меню «⋯»: тема (светлая/тёмная/системная), язык (русский/английский —
после перезапуска), новое окно, о программе.
