# Краткое руководство

## Открытие

- Кнопка «Открыть», перетаскивание PDF в окно, двойной клик по файлу
  (после назначения программы обработчиком), или `NexusPdf.exe файл.pdf`.
- Защищённый файл спросит пароль; пароль нигде не сохраняется.

## Эскизы PDF в Проводнике

- Вместо значка Проводник показывает первую страницу документа — в папках, на
  рабочем столе и в окнах выбора файла. Значок NexusPDF остаётся уголком.
- Эскизы появляются при установке «для всех пользователей»; она выбрана по
  умолчанию и один раз просит права администратора. Установка «только для меня»
  прав не требует, но эскизов не даёт: место в реестре, откуда Windows их
  берёт, пользователю недоступно.
- Эскиз виден при размере значков от «обычных» и крупнее. В «Таблице»,
  «Списке» и «Мелких значках» Windows рисует значок типа файла для всего
  подряд — там эскиза нет ни у PDF, ни у фотографий.

## Просмотр

- Прокрутка — колесо/полоса; масштаб — Ctrl+колесо, кнопки «−/+» в статус-баре,
  «по ширине», «страница целиком», Ctrl+1 — 100%.
- Слева — миниатюры, клик переходит к странице.
- Ctrl+F — поиск: Enter — дальше, Shift+Enter — назад, Esc — закрыть.
- Вкладки: Ctrl+Tab — следующая, Ctrl+W — закрыть. Меню «⋯» → «Открыть вкладку
  в отдельном окне» переносит документ в новое окно.
- F11 — полноэкранный режим (Esc — выход).

## Систематизация страниц (кнопка «Страницы»)

- Клик — выбор; Ctrl/Shift — несколько; Ctrl+A — все.
- Перетаскивание выбранных — изменение порядка (линия показывает место вставки).
- Кнопки панели: поворот ⟲/⟳/180°, дублирование, удаление (или Del),
  «Извлечь в новый PDF…» — сохраняет выбранные страницы отдельным файлом.
- Любая операция отменяется: Ctrl+Z / Ctrl+Y.

## Сохранение

- Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как.
- Исходный файл не изменяется, пока новый не записан и не проверен; при любой
  ошибке оригинал остаётся нетронутым.
- Точка «●» на вкладке — несохранённые изменения. При закрытии окна программа
  покажет список изменённых документов.

## Оформление (меню «⋯»)

- «Колонтитулы и номера страниц…» — шаблон текста с подстановками {n}, {N},
  {file}, {date}; положение, выравнивание, диапазон.
- «Водяной знак…» — текст, размер, непрозрачность, диагональ.
- «Вставить изображение…» — после диалога кликните по нужному месту страницы
  (Esc — отмена).

## Текст на странице (инструмент «Текст»)

- Включите инструмент «Текст» на панели инструментов. Щелчок по странице
  начинает строку, которая растёт вправо по мере набора; протянутая рамка —
  абзац заданной ширины с переносом по словам.
- Enter — новый абзац, Shift+Enter — новая строка в абзаце. Esc или щелчок
  мимо блока заканчивает ввод; набранное становится одним шагом отмены.
- Над блоком — панель оформления: шрифт, размер (−/+), Ж/К/Ч/зачёркнутый,
  цвет, выравнивание и «⋯» с интервалами, индексами, «Высота по тексту» и
  «Уменьшать, чтобы влезло». Оформление применяется к выделенному тексту или
  к тому, что будет набрано дальше. Ctrl+B, Ctrl+I, Ctrl+U работают тоже.
- В правой колонке — те же настройки и точные: рамка в миллиметрах, поворот,
  «Сделать оформлением по умолчанию» — новые блоки пишутся этим стилем.
- Щелчок по готовому блоку выделяет его: тяните за рамку, чтобы подвинуть, за
  ручки — чтобы растянуть, за кружок над рамкой — чтобы повернуть; Delete
  удаляет. Двойной щелчок — снова писать в блоке, в том числе после
  сохранения и повторного открытия файла.
- Буквы, которых нет в выбранном шрифте, пишутся запасным шрифтом и
  подчёркиваются в редакторе пунктиром — так видно, что на экране и в файле
  они будут другим начертанием.
- «Вставить подпись…» — библиотека ваших подписей (хранится только на этом
  компьютере, зашифрована ключом Windows). Это визуальная подпись-изображение,
  не криптографическая.
- Всё добавленное видно сразу и отменяется Ctrl+Z; в файл контент
  записывается при сохранении.

## Комментарии (кнопки в панели инструментов)

- **Заметка** — текст и автор в диалоге, затем клик по месту на странице.
- **Маркер**, **Рамка**, **Овал** — растяните прямоугольник прямо по странице.
- Кнопка «Комментарии» открывает панель со всеми аннотациями: клик — переход
  к странице; свои черновики можно удалить до сохранения (или Ctrl+Z).
- При сохранении аннотации записываются в PDF по стандарту и видны в любых
  просмотрщиках.

## Настройки

Меню «⋯»: тема (светлая/тёмная/системная), язык (русский/английский —
после перезапуска), новое окно, о программе.
