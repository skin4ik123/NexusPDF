# Отчёт приёмки печати

Дата: 2026-08-16, версия 0.17.0. Машина: Windows 11 Pro 26200.
**Физического принтера нет.** Установлены только виртуальные очереди Fax и
OneNote; Microsoft Print to PDF и XPS Document Writer отсутствуют.

Ниже — критерии приёмки из технического задания. Статусы присвоены по
фактическому прогону, а не по наличию кода.

## Не сделано

Пункты 22–23 (смешанные размеры и автоподбор бумаги в одном задании — раскладка
умеет, `PrintTicket` задаётся по первому листу), 33–34 (мастер ручного дуплекса
и его калибровка), 35–36 (копии и сортировка доводятся до `PrintTicket`, но не

## Содержимое, цвет и предварительная проверка (2026-08-16)

Раньше эти настройки существовали в модели, доходили до плана — и не влияли
ни на предпросмотр, ни на бумагу. Теперь влияют, и вот чем это подтверждено.

| Критерий | Как проверено | Итог |
| --- | --- | --- |
| Аннотация без флага Print не печатается | `PrintContentTests.Screen_Only_Annotations_Do_Not_Reach_The_Paper`: PDF собран вручную, у одной аннотации `/F 4`, у другой `/F 0`; на растре печатная есть, экранной нет | Требование спецификации соблюдается |
| «Все видимые» печатает и экранные | `All_Visible_Annotations_Is_A_Deliberate_Choice_And_Prints_Them` | Режим отличается от предыдущего не только названием |
| Пустой бланк сохраняет комментарии | `A_Blank_Form_Keeps_The_Comments`: поле формы с листа ушло, аннотация осталась | Исправлена связка, при которой снятие полей уносило всю разметку |
| Только содержимое | `Document_Only_Prints_Neither_Annotations_Nor_Fields` | |
| Фильтр не меняет документ | `Filtering_Does_Not_Leave_The_Document_Changed`: второй рендер подряд видит аннотацию снова, файл на диске байт в байт прежний | Флаг Hidden ставится и снимается внутри одного вызова |
| Оттенки серого считает программа | `PrintColorTests`: все пиксели нейтральны, порядок яркостей сохранён | Результат одинаков на любом принтере и виден в предпросмотре |
| Чёрно-белая — рассеиванием ошибки | `Monochrome_Renders_Grey_As_A_Mix_Of_Dots`: половинный серый даёт 25–75 % чёрных точек | Полутон передаётся плотностью точек, а не сплошным пятном |
| Белая бумага остаётся белой | `White_Paper_Stays_White_In_Every_Mode` | Ни один режим не пачкает поля листа |
| Цвет применяется и к меткам | Порядок в `PrintPlanRenderer`: содержимое → метки → цвет → направляющие | На сером листе не остаётся цветных меток реза |
| Предпросмотр и бумага совпадают | Преобразование живёт в общей точке `RenderSheetAsync`, которой пользуются и печать, и «Сохранить раскладку в PDF» | Расхождение невозможно по построению |
| Проверка по документу | `DocumentPreflightTests`: мягкий скан, пустой документ, серый режим на цветном принтере, слои | Обычный текстовый документ замечаний не получает |
| Замечания документа не блокируют печать | `Document_Remarks_Never_Block_Printing` | Блокировать может только запрет печати самим документом |
| Профили не теряют настройки | `Forms` дописан в `ApplyProfile` и `BuildSettings` | Профиль перестал молча ронять политику полей |

Проверено глазами на грязном скане: переключение «Цвет → Чёрно-белая» в окне
печати сразу перерисовывает лист растром точек с сохранённым градиентом
засвета. Снимок `ux/R3-monochrome.png` в рабочих материалах.

### Что осталось невозможным

Три настройки не удалось сделать честно, и они описаны в
`PRINT_KNOWN_LIMITATIONS.md`, а не спрятаны:

- «пустой бланк» убирает виджеты целиком — отделить значение от рамки
  публичный API не даёт;
- выбор набора слоёв для печати: отрисовка не принимает состояние слоёв,
  печатается видимое сейчас, о чём сообщает предварительная проверка;
- «печатать как изображение» ничего не включает: печать и так растровая, и
  подпись под флажком говорит это прямо.

Проверка встроенных шрифтов не сделана: перечисления шрифтов в API движка нет,
поэтому «шрифт не встроен» обнаружить нечем.
