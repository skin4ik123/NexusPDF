# Отчёт приёмки печати

Дата: 2026-08-15, версия 0.17.0. Машина: Windows 11 Pro 26200.
**Физического принтера нет.** Установлены только виртуальные очереди Fax и
OneNote; Microsoft Print to PDF и XPS Document Writer отсутствуют.

Ниже — критерии приёмки из технического задания. Статусы присвоены по
фактическому прогону, а не по наличию кода.

## Выполнено и проверено

| № | Критерий | Чем подтверждено |
| --- | --- | --- |

## Не сделано

Пункты 22–23 (смешанные размеры и автоподбор бумаги в одном задании — раскладка
умеет, `PrintTicket` задаётся по первому листу), 33–34 (мастер ручного дуплекса
и его калибровка), 35–36 (копии и сортировка доводятся до `PrintTicket`, но не
проверены), 37–43 (сводка комментариев, выбор слоёв, наложения печати), 44–50
(цветовые режимы доведены до `PrintTicket`, output preview и метки не сделаны),
52–53 (растеризация только проблемных страниц, калибровка масштаба), 54–55
(Print to PDF и XPS — принтеры отсутствуют), 66–74 (профили, диагностика,
доступность, полная клавиатурная проверка).

Полный разбор с причинами — [PRINT_KNOWN_LIMITATIONS.md](PRINT_KNOWN_LIMITATIONS.md).

## Вывод

Печать **не принята**: из 75 критериев подтверждено 30, ещё несколько
реализованы, но не проверяемы без устройства, остальные не сделаны.
Заявлять готовность до подключения принтера и прогона физических листов
нельзя.
