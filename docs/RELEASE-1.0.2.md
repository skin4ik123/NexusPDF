# NexusPDF 1.0.2

Исправления к 1.0.1.

- Верхняя панель с подписями («Оптимизация документа…» и другие) больше не уходит за край окна на узком окне и маленьком экране. Раньше на экранах с масштабом до 125 % программа ошибалась в ширине подписей, и кнопки оказывались за краем. Теперь, если подписи не помещаются, остаются значки, а подписи возвращаются, когда места хватает.
- Ряд инструментов выбранной группы — комментарии и рисование, правка, измерение, защита, страницы — переносится на вторую строку, а не обрезается справа.

В выпуске один установщик для Windows x64, со всеми движками и языковыми пакетами OCR.
