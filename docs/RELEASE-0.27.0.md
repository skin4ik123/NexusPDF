# NexusPDF 0.27.0

Большое обновление после полного аудита функций, реальных окон Windows и сценариев сохранения.

- Изменение страницы обновляет только затронутые страницы. Миниатюры, выделение и положение в документе сохраняются; корректно обрабатываются и дубликаты страниц.
- Поиск сразу убирает устаревшие результаты и обновляется после правок. Фоновое обновление не переводит читателя на другую страницу.
- Word и Excel получают актуальное содержимое, включая несохранённые правки, повороты и применённые вымарки. Заметки на полях и пустых страницах сохраняются в Word. Исправлены ошибки структуры DOCX.
- При переключении OCR выбранный движок применяется и к экспорту. Выполняющаяся операция завершает работу со своим движком без преждевременного освобождения ресурсов.
- В экспорте изображений можно выбрать все страницы, текущую страницу или диапазон, а для JPEG — качество. Выделение в организаторе подставляется в окно экспорта.
- Панель команд адаптируется к ширине окна. Исправлены обрезанные ссылки и подсказки, улучшены списки и прокрутка в тёмной теме. Пустые пакеты нельзя отправить на обработку или печать.
- Свойства выбранного объекта, текста и страницы больше не накладываются друг на друга. Страница с полями формы получает подходящую подсказку.
- Повторный клик во время опроса принтера не запускает вторую пакетную печать. Отмена доступна уже при подготовке задания.
- Временные PDF и запечённые страницы освобождаются при закрытии документов. Переданные между вкладками страницы продолжают работать; сохранённые пользователем результаты остаются на диске.
- Консольный импорт JPEG сохраняет исходное сжатие. Консольный экспорт поддерживает `--pages` и `--quality`, сохраняет результаты атомарно и не удаляет другие экспортированные страницы.
- Установщик удаляет свой распакованный временный MSI, включая неудачную установку.

Поставляется один установщик для Windows x64 с PDF-движками, консольной версией и OCR-моделями. Выпуск допускается только после тестов PDF/OCR/печати, проверки всех диалогов и проверки установленной программы.

Физическая печать на конкретном устройстве и работа Microsoft Office проверяются на машине с соответствующим оборудованием и установленным Office. Windows-проверки используют реальные системные компоненты и виртуальный принтер.
