# Конфиденциальность

- Документы обрабатываются **только локально**. Программа не выполняет
  сетевых запросов: ни телеметрии, ни облачных функций, ни автообновлений
  (updater появится позже и будет спрашивать разрешение).
- Журналы (`%LOCALAPPDATA%\NexusPDF\Logs`) содержат пути к файлам и технические
  сообщения; содержимое документов и пароли туда не попадают. Журналы никуда
  не отправляются.
- Список недавних файлов и открытая сессия хранятся в `settings.json` локально;
  очищаются удалением файла (позже — кнопкой в настройках).
- Внешние ссылки внутри PDF не открываются автоматически (переход по ссылкам
  появится вместе с подтверждением действия).
