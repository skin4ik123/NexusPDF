# NexusPDF 0.27.2

Гибридные XFA-формы показываются заполненными и заполняются.

- Гибридная форма — обычные поля AcroForm и XFA поверх них (так устроены, например, бланки CBP). Раньше NexusPDF рисовал такие поля пустыми и на экране, и на печати. Теперь значения видны везде: на экране, при печати и при экспорте страниц, как в Chrome, Firefox и Adobe Reader.
- Такую форму можно заполнить. Adobe Reader берёт значения не из полей AcroForm, а из данных XFA, поэтому при сохранении изменённые значения записываются и туда — по тем же правилам привязки, что у Adobe. Нетронутые поля не меняются; подписи и пароль файла сохраняются.
- Поля с общим значением, например название судна в шапке каждой страницы, заполняются вместе, как в Acrobat.
- Поле, которому в данных XFA нет места, остаётся только для чтения: введённое в него Adobe Reader не показал бы.
- Полностью динамическая XFA-форма не отображается, как и раньше. Теперь об этом прямо говорит значок «XFA: не отображается», и страницы больше не выглядят пустыми без объяснения.

В выпуске один установщик для Windows x64, со всеми движками и языковыми пакетами OCR.
