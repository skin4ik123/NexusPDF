# NexusPDF 0.27.1

Исправлено зависание страницы на «Отрисовка…» после действий с PDF, появившееся в версии 0.27.0.

- Исправления страницы, повороты, отмена и повтор, удаление, вставка и перестановка снова автоматически обновляют изображение.
- Миниатюры обновляются при замене страницы в существующей карточке.
- Быстрый уход со страницы и возврат больше не оставляют её с отменённым запросом отрисовки.
- Переиспользование карточек сохраняет ускорение небольших правок; открытая карточка не теряет изображение при закрытии другой карточки той же страницы.
- Визуальные проверки ждут автоматической отрисовки и сравнивают показанные пиксели с текущим PDF. Убрана ручная перерисовка, скрывавшая этот сбой в прежней проверке.

В выпуске один установщик для Windows x64, со всеми движками и языковыми пакетами OCR. Возможности 0.27.0, включая включение форм одним нажатием, сохранены.
