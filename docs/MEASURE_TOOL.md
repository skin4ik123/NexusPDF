# Инструмент «Измерение»

Группа «Измерение» на левом рельсе. Три инструмента и калибровка:

| Инструмент | Как работает | Что остаётся на листе |
| --- | --- | --- |
| Расстояние | два щелчка | размерная линия с засечками и подписью |
| Периметр | щелчки по точкам; Enter, двойной щелчок или правая кнопка — закончить | ломаная с отметками вершин и подписью длины |
| Площадь | щелчки по вершинам; замкнуть щелчком по первой точке или Enter | контур с полупрозрачной заливкой и подписью площади |
| Калибровка | две точки отрезка с известной длиной → ввод длины | меняет масштаб, ничего не рисует |

Клавиши: **Shift** — угол кратен 45°, **Alt** — без привязки на один щелчок,
**Backspace** — убрать последнюю точку, **Esc** — отменить начатое, второй Esc —
убрать инструмент.

## Привязка

Курсор прилипает к векторной графике страницы: концы отрезков, пересечения,
середины, затем ближайшая точка на линии (приоритет в этом порядке) — радиус
10 экранных точек. Геометрия читается движком один раз на страницу
(`IPdfDocumentHandle.GetPageSegmentsAsync`, кривые Безье раскладываются на
отрезки, контуры букв и невидимые пути отбрасываются) и раскладывается по
сетке (`VectorSnapIndex`). На плане судна 1:200 это 458 688 отрезков за полсекунды.

Свои поставленные точки — тоже цели привязки: так замыкается контур площади.

## Масштаб

Масштаб — «во сколько раз натура больше листа» (`ScaleRatio`): 200 для 1:200.

1. При первом включении линейки читается текст текущей страницы: найдено
   «SCALE 1:200» / «Масштаб 1:50» / «М 1:100» — масштаб подставляется, об этом
   сообщает строка состояния.
2. Поле «Масштаб» на панели: «1 : 200», «200», «1/200», «2:1».
3. Калибровка по известному отрезку: длина вводится с единицей или без
   («22080 мм», «22,08 м», «72 ft»).

Словарь `/Measure` (viewport) из самого PDF не читается: pdfium его не отдаёт,
а в чертежах из печатных драйверов его и нет.

Масштаб, единица, число знаков и привязка запоминаются в настройках. Каждое
измерение хранит СВОЙ масштаб и единицу (как в Acrobat): смена масштаба
документа не перерисовывает прежние размеры.

## Как хранится

`MeasurementDraft` — обычный оверлей страницы (точки в отображаемых пунктах,
`PlacedRotation`), поэтому отмена, перенос при повороте, выбор и удаление
работают как у остальных. При сохранении — аннотация **Stamp** с собственным
внешним видом из объектов (пути и текст CID-шрифтом): pdfium не строит внешний
вид для Line/Polygon, и такие аннотации были бы невидимы. Параметры лежат в
строке `/NexusMeasure` («Distance;200;Meter;2»), `/Subj (Measurement)`,
`/Contents` — подпись, флаг Print выставлен.

## Проверка на реальном чертеже

General Arrangement, 2200×841 мм, 1:200: привязка к углам люка №5 даёт
312,963 пт → 22,0812 м (на чертеже 22 080 мм); калибровка по этому отрезку
возвращает масштаб 199,99.
